
# African Buffalo 商业版深度拆解分析（V1.0）

# 一、最终目标

Asian Buffalo 最终验收必须同时满足：

1. 工程标准
- 服务端权威
- Wallet / Ledger 安全
- RTP 与数学版本冻结
- 多语言
- PC / 平板 / 手机
- 性能稳定

2. 商业标准
- 第一眼达到成熟商业老虎机品质
- 手机体验达到国际商业游戏水准
- 不低于 African Buffalo 的整体完成度

# 二、视觉总原则

- 游戏区域（Reel）是第一视觉主体。
- 背景服务于游戏，不喧宾夺主。
- 金属、玻璃、高光、阴影统一。
- 所有图标、字体、按钮风格统一。

# 三、Reel（最高优先级）

必须：
- 左右接近屏幕边缘
- 横向尽可能铺满屏幕
- 保留必要安全边距
- 手机端优先布局

禁止：
- 左右大量留白
- 为了显示背景而缩小 Reel

# 四、HUD

顶部：
- 余额
- 设置
- 菜单
- 多语言

底部：
- Bet
- Win
- Balance
- Auto
- Spin（主视觉）

要求：
- 金属质感
- 高光
- 悬浮反馈
- 动态数字
